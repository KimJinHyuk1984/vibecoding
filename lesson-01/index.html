02 / PLAY FIRST · 5 MIN

만들기 전에, 한 판 해볼까요?

왼쪽 방향키(←)로 방향 전환, 오른쪽 방향키(→)로 올라가기. 다음 계단을 보고 얼마나 높이 올라갈 수 있는지 도전해보세요.

무한의 계단 게임

시작 → ←로 바라보는 방향 바꾸기 → →로 한 칸 올라가기. 다음 계단과 방향이 다르면 게임이 끝납니다. 제한 시간은 없습니다. JavaScript가 꺼져 있으면 이 체험 대신 다음 프롬프트로 직접 만들어보세요.

방금 플레이하면서 무엇을 바꾸고 싶었나요?

제목, 안내 문구, 기록 표시, 버튼 크기… 하나만 골라 기억해두세요. 이 페이지의 게임은 체험용 예제이며, 여러분이 AI로 만드는 게임은 모양이 달라도 괜찮습니다.

  3. 다음 프롬프트를 복사해서 붙여넣어요.이후 수정 요청은 같은 채팅에서 이어갑니다.

HTML 파일로 실행하기
  1. AI가 준 HTML 코드 전체를 복사합니다.코드를 감싼 백틱(```)과 설명 문장은 제외합니다.

  3. 저장한 파일을 Chrome으로 엽니다.파일 이름이 stairs-game.html.txt가 아닌지 확인하세요. Chromebook 등 다른 기기에서는 선생님이 안내한 HTML 저장 도구를 사용합니다.

04 / FIRST PROMPT · 25 MIN

첫 프롬프트, 첫 게임

‘복사’를 누른 뒤 Gemini에 붙여넣고 보내세요. 생성이 끝나면 미리보기에서 실행합니다.

무엇을 · 어떻게 · 어떤 조건으로

무엇을: 무한의 계단 게임
어떻게: ←로 방향만 바꾸고, →로 바라보는 쪽으로 한 칸 올라가기
어떤 조건으로: 한 파일로 만들고 키보드도 지원하기

아래 프롬프트에서 이 세 가지를 찾아본 다음 복사해보세요.

도형 캐릭터로 ‘무한의 계단’ 방식의 게임을 만들어줘.
HTML, CSS, JavaScript를 한 HTML 파일로, 외부 연결 없이 만들어줘.
Canvas 미리보기와 저장한 HTML 파일에서 실행되게 해줘.

1. 시작하면 0칸, 캐릭터와 첫 계단은 오른쪽 방향으로 해줘.
2. 왼쪽 방향키(←)는 제자리에서 좌우 방향만 바꾸게 해줘.
3. 오른쪽 방향키(→)는 바라보는 방향으로 한 칸 올라가게 해줘.
4. 다음 계단과 방향이 다르면 게임을 끝내고 오른 칸 수를 보여줘.
5. 계단은 좌우로 계속 생성하고, 올라가도 다음 계단이 화면에 보이게 해줘.
6. 화면에도 ‘← 방향 전환’과 ‘→ 올라가기’ 버튼을 만들어줘.
7. 한 번 누르면 한 번만 동작하고, 방향키로 페이지가 스크롤되지 않게 해줘.
8. ‘다시 시작’은 점수·위치·방향을 처음 상태로 되돌려줘.

제한 시간 없이, 현재 방향과 칸 수를 큰 글씨로 보여줘.
  1. AI가 코드를 다 만들 때까지 기다려요.답변이 중간에 끊기면 ‘끊긴 부분을 이어서 완성해줘’라고 요청합니다.
  2. 미리보기에서 시작 버튼을 눌러요.코드만 보이면 미리보기 화면으로 바꾸거나 HTML 파일로 저장해서 실행합니다.
  3. 직접 한 판을 끝까지 해봐요.여기 있는 예제와 디자인이 달라도, 요청한 동작이 되면 첫 단계 성공입니다.
첫 시도에 완성되지 않아도 괜찮아요.

화면이 비거나 버튼이 안 되면 ‘오류를 설명하는 법’의 프롬프트를 사용하세요. 작동하는 버전이 생기면 수정하기 전에 코드를 복사해 Docs에 ‘게임 v1’로 남깁니다.

내가 만든 게임에서 아래 행동을 해보고, 실제로 확인한 항목만 체크하세요.

직접 확인한 뒤 체크하세요.

왼쪽을 보고 있어도, 올라갈 때는 →

←는 방향 전환, →는 올라가기라는 명령이에요. 왼쪽 계단을 오르려면 왼쪽을 바라보도록 바꾼 뒤 →를 누릅니다.

←만 눌렀는데 이동하거나 점수가 늘면 요청과 다르게 만들어진 거예요. 오른 칸 수가 많을수록 높은 기록입니다. 먼저 조작 규칙이 맞는지 확인해요.

쉬고 돌아오면 제목·디자인·기록 중 원하는 기능 하나를 바꿔봅니다.

06 / MAKE IT YOURS · 20 MIN

복사한 게임에 내 생각 한 가지

아래 미션 중 하나를 고르세요. 같은 채팅에 보내고, 바뀐 결과를 실행해서 확인합니다.

A. 제목과 분위기 바꾸기

‘하늘 계단 챌린지’를 자신이 정한 제목으로 바꿔서 보내보세요.

지금 만든 게임의 제목을 ‘하늘 계단 챌린지’로 바꿔줘.
도형 캐릭터와 계단을 레트로 게임 분위기로 꾸며줘.
현재 방향, 다음 계단, 게임 종료 상태를 알아보기 쉽게 해줘.
배경과 글자 색의 차이를 충분히 크게 해줘.
←는 방향 전환, →는 올라가기인 조작과 점수 규칙은 유지해줘.

B. 최근 기록과 최고 기록 추가하기

앞에서 만든 게임에 데이터가 쌓이는 경험을 더합니다. 오늘은 창을 닫으면 기록이 사라져도 괜찮아요.

게임이 끝날 때 오른 칸 수를 최근 5판의 기록에 추가해줘.
그중 가장 큰 값을 ‘최근 5판 최고 기록’으로 보여줘.
한 판은 한 번만 기록하고, 중간에 다시 시작한 판은 제외해줘.
‘기록 초기화’ 버튼은 기록을 지우고 게임도 시작 전으로 돌려줘.
새로고침하면 기록이 사라져도 괜찮아.
← 방향 전환·→ 올라가기 규칙과 기존 디자인은 유지해줘.

C. 작은 화면에서도 편하게 만들기

미리보기 폭을 줄이거나 휴대폰 크기로 생각하며 확인해보세요.

지금 게임을 작은 화면에서도 편하게 할 수 있게 바꿔줘.
가로 375px 화면에서 옆으로 스크롤되지 않게 해줘.
‘← 방향 전환’과 ‘→ 올라가기’ 버튼을 터치하기 충분히 크게 해줘.
캐릭터, 다음 계단, 칸 수와 현재 방향이 가려지지 않게 해줘.
터치 한 번이 두 번의 입력으로 처리되지 않게 해줘.
기존 방향키 조작과 기록 기능이 있다면 그대로 유지해줘.
추가 → 실행 → 기존 기능도 확인

기능 하나를 바꾼 뒤 처음부터 한 판 해보세요. 잘 되면 다음 아이디어를 추가합니다. 문제가 생기면 이전 버전과 무엇이 달라졌는지 비교해요.

07 / FIX IT · 15 MIN

“안 돼요”를 해결 가능한 설명으로

언제, 무엇을 했고, 어떤 결과가 나왔는지 알려주면 AI가 원인을 찾는 데 도움이 됩니다.

“게임이 이상해. 고쳐줘.”

“왼쪽 방향키를 눌렀더니, 방향도 바뀌고 한 칸 올라갔어. ←는 제자리에서 방향만 바꾸게 해줘.”

내 행동 · 실제 결과 · 기대한 결과가 모두 들어 있습니다.

지금 게임에서 아래 문제가 생겼어. 원인을 찾고 수정해줘.

내가 한 행동: [예: 왼쪽 방향키(←)를 한 번 눌렀어]
실제로 나온 결과: [예: 방향이 바뀌면서 한 칸 올라갔어]
기대한 결과: [예: 제자리에서 방향만 바뀌고 점수는 그대로여야 해]
오류 메시지: [있으면 그대로 붙여넣고, 없으면 ‘없음’]

대괄호 안 내용은 내가 겪은 상황으로 바꿔서 보낼게.
관련 없는 디자인과 기능은 유지해줘.
수정한 이유와 내가 다시 확인할 행동 3가지를 알려줘.
[대괄호] 안을 내 상황으로 바꿉니다.

접속 제한이나 로그인이 안 되는 문제는 선생님에게 보여주세요. 코드 오류를 해결할 때는 오류 문구를 그대로 붙이되, 계정 정보나 비밀 키가 포함되어 있지 않은지 확인합니다.

지금 게임의 코드를 바꾸지 말고 설명만 해줘.
1. 캐릭터가 바라보는 방향을 어떻게 기억하고 바꿔?
2. →를 눌렀을 때 올라갈지, 게임을 끝낼지 어떻게 판단해?
3. 계단은 어떻게 계속 만들고 화면에 보여줘?
실제 코드의 해당 부분을 짧게 인용하고 쉽게 설명해줘.
설명한 내용이 맞는지 내가 해볼 테스트도 하나 제안해줘.
