“이런 게임을 만들어줘.”
내 말이 출발점이에요.

바이브코딩은 AI에게 원하는 동작을 설명하고, 만들어진 프로그램을 실행·확인·수정하는 방식이에요. AI에게 보내는 부탁을 프롬프트라고 부릅니다.

나는 만들 것과 잘됐는지를 판단하고, AI는 코드를 작성하고 고쳐요. “완성했어”라는 답을 받아도 직접 확인해야 해요.

02 / MY WORKSPACE

복사하고, 실행하고, 결과 보기

강의 페이지와 AI 채팅을 함께 열어요. 이번 프로젝트는 같은 채팅에서 이어갑니다.

  1. 학교에서 안내한 계정으로 AI를 열어요.Gemini에서 Canvas가 보이면 선택해요. 접속이나 도구 사용이 막히면 선생님과 학교에서 허용한 환경을 확인합니다.

  3. 프롬프트의 복사 버튼을 눌러 AI에게 보내요.답변이 끝나면 미리보기에서 실행해요. 한 번에 하나씩 부탁하고 바뀐 모습을 확인합니다.

그대로 옮길 것

AI가 만든 코드는 복사 버튼으로 전체를 가져와요. 줄을 찾아 고치지 않아요.

답변이 일부뿐이면 “통째로 복사할 수 있게 파일 전체를 줘”라고 말해요. 새 채팅을 열면 지금 쓰는 파일 전체도 함께 줍니다.

  1. AI 답변의 HTML 코드 전체를 복사해요.코드 옆 복사 버튼을 쓰면 설명 문장을 따로 골라낼 필요가 없어요.

  3. 파일을 Chrome으로 열어요.파일 이름이 index.html.txt가 아닌지 봐요. 이 방법은 첫 게임 확인용이고, 시트 저장 단계에서는 배포한 게임 주소를 사용해요.

03 / BUILD MY FIRST GAME

첫 부탁으로 움직이는 게임 만들기

처음 목표는 한 판을 끝까지 해보는 것입니다. 복사해서 AI에게 보내고 결과를 기다려요.

친구들과 할 수 있는 ‘무한의 계단’ 게임을 만들어줘.
캐릭터가 지그재그 계단을 한 칸씩 올라가는 게임이야.
처음에는 0칸이고, 캐릭터와 첫 계단은 오른쪽 방향으로 해줘.
←를 누르면 제자리에서 바라보는 방향만 바뀌게 해줘.
→를 누르면 바라보는 쪽으로 한 칸 올라가게 해줘.
계단이 없는 쪽으로 올라가면 게임이 끝나게 해줘.
올라갈수록 새 계단이 계속 보이고, 오른 칸 수는 크게 보여줘.
버튼을 꾹 눌러도 한 번만 움직이고, 페이지는 위아래로 밀리지 않게 해줘.
화면에도 ‘← 방향 전환’과 ‘→ 올라가기’ 버튼을 크게 넣어줘.
‘다시 시작’을 누르면 0칸부터 처음 위치와 방향으로 돌아가게 해줘.
시간제한은 넣지 말고, 캐릭터는 간단한 도형으로 그려줘.
미리보기와 파일 하나에서 실행할 수 있는 게임 HTML 전체를 줘.
  1. 미리보기에서 시작 버튼을 눌러요.모양이 체험 예제와 달라도 괜찮아요. 화면이 안 나오면 아래 도움 프롬프트를 사용해요.
  2. ←와 →를 각각 눌러봐요.←는 제자리에서 방향만 바꾸고, →는 바라보는 쪽으로 한 칸 올라가야 해요.
  3. 일부러 틀린 쪽으로 올라간 뒤 다시 시작해요.게임이 끝나는지, 다시 시작하면 0칸·처음 위치·오른쪽 방향으로 돌아오는지 확인해요.

막히면 문제 해결 프롬프트로 이동하세요. 잘되면 게임 전체와 화면을 Docs의 ‘v1 · 첫 게임’ 아래에 보관합니다.

06 / ASK AI TO CONNECT

저장할 코드도 직접 요청하기

Docs의 v2 또는 미리보기에서 내 최신 게임 HTML 전체를 가져와 PROMPT 03과 함께 보내세요. 같은 채팅에서 04로 이어갑니다.

지금 함께 붙이는 HTML은 내가 꾸민 무한의 계단 게임이야.
이 게임의 기록을 Google Sheets에 저장할 Code.gs 전체를 만들어줘.
두 파일을 같은 Google Apps Script 프로젝트에 넣어 실행할 거야.
시트 주소는 ‘프로젝트 설정 → 스크립트 속성’에 SHEET_URL이라는 이름으로 넣을게.
그 주소의 시트를 사용하고, 코드 속에서 주소를 찾아 고치지 않게 해줘.
‘기록’ 탭과 열 제목이 없으면 처음 저장할 때 만들고, 기존 기록은 지우지 마.
끝난 판의 별명, 칸 수, 저장 시각을 한 판에 한 줄씩 남겨줘.
같은 판을 여러 번 보내거나 친구와 동시에 저장해도 기록이 겹치지 않게 해줘.
별명은 한글·영문·숫자 2~12자, 칸 수는 0~10000의 정수만 받아줘.
저장이 됐는지 알려주고, 실패하면 알아볼 수 있는 안내를 보내줘.
별명별 최고 기록을 높은 순서로 10명까지 불러오는 기능도 만들어줘.
동점은 같은 순위야. 12, 12, 8칸이면 1, 1, 3위로 해줘.
게임 주소를 열면 같은 프로젝트의 index.html이 보이게 해줘.
이번에는 Code.gs만 전체로 줘. 다음에 내 게임을 여기에 연결할 거야.
방금 함께 준 내 게임 HTML을 지금 만든 Code.gs와 연결해줘.
게임 모양과 ← 방향 바꾸기·→ 올라가기, 점수와 다시 시작은 그대로 해줘.
한 판이 끝나면 별명 입력칸과 ‘기록 저장’ 버튼을 보여줘.
점수는 끝난 판에서 오른 칸 수를 쓰고, 직접 고칠 수 없게 해줘.
저장 중에는 ‘저장 중…’을 보여주고 별명 수정·저장·새 게임은 잠깐 막아줘.
실제로 저장됐다는 확인을 받은 뒤에만 ‘저장 완료’라고 알려줘.
확인이 안 되면 같은 판의 별명과 점수를 그대로 다시 보낼 수 있게 해줘.
여러 번 시도해도 같은 판은 한 줄만 남고, 실패해도 점수가 사라지면 안 돼.
새 판을 시작하면 이전 판의 저장 결과와 섞이지 않게 해줘.
Apps Script의 게임 주소에서 실행할 거야. 미리보기에서는 저장이 안 된다고 알려줘.
방금 만든 Code.gs를 사용하고, 게임과 저장 기능이 담긴 index.html 전체를 줘.
  1. Code.gs에는 PROMPT 03의 답변 전체를 넣어요.Apps Script 왼쪽 Code.gs를 클릭하고 기존 내용을 전부 지운 뒤 새 내용을 붙여넣어요.
  2. 파일 옆 + → HTML → 이름을 index로 입력해요.소문자 index.html이 생기면 PROMPT 04의 답변 전체를 붙여넣어요.
  3. 저장하고 파일 이름을 확인해요.Code.gs는 저장 담당, index.html은 내 게임이에요. 같은 채팅에서 만든 두 파일을 한 쌍으로 사용해요.

참고: Google · HTML 파일과 웹앱 ↗

  1. 왼쪽 톱니바퀴 ‘프로젝트 설정’을 열어요.아래 ‘스크립트 속성’에서 속성 추가를 선택해요.
  2. ‘속성’은 SHEET_URL, ‘값’은 내 시트 주소 전체예요.대문자와 밑줄까지 그대로 입력하고, 메모해둔 스프레드시트 주소를 붙여넣어요.
  3. 스크립트 속성을 저장해요.이제 코드가 어느 시트에 기록할지 알 수 있어요. 주소 속 일부나 코드 줄을 고칠 필요는 없어요.

참고: Google · 설정 화면에 속성 추가하기 ↗

07 / PLAY AND SAVE

내 게임에서 실제 점수 저장하기

이제 AI 미리보기에서 배포한 게임 주소로 옮겨갑니다. 그 주소에서 한 판을 해보고 시트를 확인해요.

  1. 배포 → 새 배포 → 유형 ‘웹 앱’을 선택해요.설명은 ‘첫 저장’으로 적어요.
  2. 실행 사용자는 ‘나’, 접근 범위는 학교 내부로 설정해요.권한 요청을 확인해요. 내부 옵션이 없거나 차단되면 선생님과 학교에서 허용한 계정을 확인해요.
  3. 배포 후 /exec로 끝나는 웹앱 주소를 열어요.내 게임이 나오는지 확인해요. 이 주소를 개인 Docs에 ‘게임 주소’로 보관합니다.

참고: Google · 웹앱 배포와 실행 권한 ↗

  1. 배포한 게임에서 짧게 한 판을 마쳐요.실명 대신 별명을 쓰고 ‘기록 저장’을 눌러요. 끝난 판의 칸 수를 기억해요.
  2. 시트에 생긴 ‘기록’ 탭을 열어요.내 별명과 실제 칸 수가 새 줄에 들어왔는지 확인해요. 열 이름은 AI가 정한 것이어도 괜찮아요.
  3. 게임을 새로고침하고 시트의 기록도 확인해요.게임이 다시 열려도 시트의 한 줄은 남아야 해요. 랭킹 표는 다음 단계에서 붙입니다.

여기까지 되면 ‘v3 · 첫 저장’으로 두 파일과 화면을 보관해요. 쉬었다 이어간다면 이 지점이 좋습니다.

직접 확인한 뒤 체크하세요.

08 / PLAY TOGETHER

친구의 기록이 내 화면에도 보이게

한 팀의 게임 주소에 함께 접속하고 서로 다른 별명을 써요. 다른 팀의 주소에서는 다른 랭킹이 보입니다.

내 게임 아래에 ‘우리 반 랭킹’과 ‘랭킹 새로고침’ 버튼을 넣어줘.
우리가 만든 Code.gs의 불러오기 기능으로 시트 기록을 읽어줘.
순위·별명·칸 수를 표에 보여줘. 별명마다 최고 기록 하나씩, 10명까지야.
동점은 같은 순위야. 12, 12, 8칸이면 1, 1, 3위로 보여줘.
처음 열 때, 저장이 끝났을 때, 새로고침 버튼을 누를 때 읽어줘.
‘불러오는 중’, ‘아직 기록이 없어요’, ‘다시 불러와주세요’를 상황에 맞게 보여줘.
저장은 됐는데 표만 못 읽으면, 다시 저장하지 말고 표만 다시 불러와줘.
게임 모양과 조작은 그대로 두고, 바뀐 파일은 이름과 전체 내용을 줘.
  1. AI가 바꾼 파일 전체를 같은 이름의 파일에 붙여요.둘 다 바뀌었다면 Code.gs와 index.html을 모두 교체하고 저장해요.
  2. 배포 → 배포 관리 → 연필 아이콘을 눌러요.‘새 버전’을 선택해 배포합니다. 코드 저장만으로 친구 화면이 바뀌지는 않아요.
  3. 기존 게임 주소를 새로고침해요.랭킹이 보이는지, 시트의 이전 기록이 남아 있는지 확인해요.

친구의 새 기록

친구가 저장한 뒤 내 랭킹 새로고침을 눌러요. 시트에도 그 기록이 있어야 해요.

같은 별명으로 낮은 점수 / 같은 점수

낮은 기록을 저장해도 최고 기록은 유지돼요. 12·12·8칸은 1·1·3위예요.

저장 버튼 여러 번 누르기

같은 판은 시트에 한 줄만 생겨야 해요. 서로 다른 판은 각각 남아야 해요.

반 전체가 비교할 때도 완성한 앱 하나의 같은 게임 주소를 써요. 이 랭킹은 저장 실습용이며 점수 조작을 판별하는 대회용 앱은 아니에요.

직접 확인한 뒤 체크하세요.

09 / KEEP IT AND GO FURTHER

내가 만든 것을 남기고, 다음 아이디어로

게임 만들기부터 저장과 공유까지 연결했어요. 실제로 작동한 버전과 내가 배운 제작 방법을 남깁니다.

지금 만든 게임과 저장 기능을 다음에도 이어서 만들고 싶어.
완성한 Code.gs와 index.html 전체를 파일별로 나눠서 줘.
생략하거나 새 기능을 넣지 말고, 지금 잘되는 모습을 유지해줘.
각 파일을 어디에 붙이고, 시트 주소는 어느 설정에 넣는지 짧게 알려줘.
고친 내용을 기존 게임 주소에 반영하는 순서도 알려줘.
내가 직접 확인할 것 3개와 결과를 적을 빈칸도 만들어줘.
  1. 실제로 실행한 두 파일 전체를 Docs에 보관해요.Apps Script의 Code.gs와 index.html을 복사해 ‘v4 · 공유 랭킹’으로 남겨요. 이전 v1·v2·v3도 유지합니다.
  2. 시트 주소와 게임 주소를 구분해 적어요.다른 프로젝트로 옮기면 시트 주소 설정도 다시 해야 해요.
  3. 직접 본 결과를 함께 남겨요.저장된 한 줄, 친구의 랭킹, 고친 문제를 적어요. AI의 “완료” 답변과 내 확인 결과는 구분합니다.

기록은 Docs에도 옮겨두세요. 개인정보나 실제 시트 주소는 적지 않아요.

OPTIONAL / AFTER MY FIRST SERVICE

완성한 뒤 골라서 더해보기

공유 랭킹까지 확인했다면 하나만 골라 바꿔보세요. 수정 전 버전을 남기고, 바뀐 파일 반영 → 새 버전 배포 → 게임과 저장 재확인 순서로 진행해요.

내 화면에서 최근 5판의 점수를 돌아보고 싶어.
끝까지 한 판만 목록에 넣고, 같은 판을 두 번 넣지 않게 해줘.
그 5판 중 가장 높은 점수를 ‘최근 5판 최고 기록’으로 보여줘.
중간에 다시 시작한 판은 목록에 넣지 마.
‘내 화면 기록 지우기’를 누르면 이 목록만 지워줘.
시트의 기록과 친구들의 랭킹은 지우거나 바꾸면 안 돼.
이 목록은 새로고침하면 사라져도 괜찮아.
잘되던 게임과 저장 기능을 유지하고, 바뀐 파일 전체를 줘.
우리 랭킹 게임을 휴대폰에서도 편하게 하고 싶어.
화면을 옆으로 밀지 않아도 게임과 랭킹이 보이게 해줘.
‘← 방향 전환’과 ‘→ 올라가기’를 손가락으로 누르기 쉽게 크게 해줘.
버튼 때문에 캐릭터, 다음 계단, 칸 수가 가려지지 않게 해줘.
한 번 누르면 한 번만 움직여야 해.
별명 입력과 저장 버튼도 편하게 쓸 수 있게 해줘.
컴퓨터 방향키와 시트 저장·랭킹은 그대로 유지하고, 바뀐 파일 전체를 줘.
20칸에서 멈추는 연습 놀이

기본 게임과 어떻게 다른지 체험해보세요. 이 모드를 만들지 않아도 본 프로젝트를 완성할 수 있어요.

완성한 게임에 ‘끝없이’와 ‘20칸 도착’을 고르는 버튼을 넣어줘.
기본은 끝없이 올라가는 지금 게임이고, 이 기록만 랭킹에 저장해줘.
20칸 도착은 현재 칸 수와 목표를 보여주고, 20칸이면 ‘도착!’이라고 해줘.
20칸 도착의 성공·실패 기록은 시트와 랭킹에 저장하지 마.
게임 전과 끝난 뒤에만 놀이를 바꿀 수 있게 해줘.
어느 놀이든 계단이 없는 쪽으로 올라가면 실패야.
성공·실패 뒤에는 버튼을 눌러도 움직이거나 점수가 늘면 안 돼.
다시 시작하면 고른 놀이 그대로 0칸·처음 위치·오른쪽 방향으로 돌아가게 해줘.
디자인과 조작은 유지하고, 두 파일을 함께 확인해 바뀐 파일 전체를 줘.
