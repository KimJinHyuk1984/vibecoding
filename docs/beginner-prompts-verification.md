# 입문자 프롬프트 수정 검증

> 통합 이전 시점의 검증 기록입니다. 현재 페이지 기준은 [통합 1회 검증](lesson-01-merged-verification.md)입니다.

검증일: 2026-10-01

> 이 기록 이후 3회는 교사 코드 제공 없이 AI에게 두 파일을 요청하는 흐름으로 개편했다. 3회의 현재 검증은 [AI 생성 흐름 검증](lesson-03-ai-flow-verification.md)을 기준으로 한다. 1~2회 수정 내용은 유지한다.

## 반영한 피드백

학생이 코드를 읽을 줄 모른다는 전제로 1~3회 프롬프트 22개를 다시 작성했다. 원하는 화면, 누를 버튼, 눈에 보이는 결과를 일상적인 말로 요청한다. 오류 설명에서는 학생이 직접 본 일만 대괄호에 적는다. 코드 일부를 찾아 수정하는 대신 AI에게 전체 파일을 받아 복사하도록 안내한다.

- 1회: 게임 제작·꾸미기·기록·휴대폰 화면·문제 설명·추가 확인·보관, 7개.
- 2회: 게임 확인·내 생각 정리·디자인·20칸 도착·문제 설명·두 놀이 비교·보관, 7개.
- 3회: 원하는 랭킹 설명·연결 확인 화면·게임 붙이기·저장 안내·랭킹·문제 설명·친구와 시험·보관, 8개.

학생용 프롬프트에서 함수 이름, 통신 호출, 자료 형식, 언어별 구현 지시를 제거했다. 코드 인용·해석 활동은 직접 조작해서 예상과 실제를 비교하는 활동으로 바꿨다. 3회 API 설명 슬라이드는 저장 버튼과 랭킹 새로고침 버튼의 결과를 확인하는 안내로 교체했다.

3회는 제공된 원본 연결 파일 전체를 AI에게 먼저 주고 같은 채팅에서 이어가는 방식이다. AI가 기존 연결 규칙을 읽을 수 있도록 파일 제공 단계를 명시했다. 시트 연결값 입력과 최초 설정 실행은 교사가 돕는다. Code.gs와 Index.html은 복사할 위치를 구분하는 파일 이름으로 소개한다. 교사용 운영 메모에는 실제 설정 절차와 기존 API 설명을 유지했다.

회차별 120분 구성, 기본 게임 조작, 두 모드, 랭킹 규칙, 기존 복사 기능은 유지했다. 게임·저장 예제 실행 코드는 이번 피드백으로 변경하지 않았다.

## 브라우저 확인

Windows의 Chrome 154 headless와 로컬 정적 서버에서 기존 CDP 검증 도구를 재사용했다. 이번 변경에 해당하는 복사·표시·발표 동작을 확인했으며 게임과 서버의 기존 기능 테스트는 반복하지 않았다.

| 항목 | 결과 |

| 프롬프트 복사 | 22개 모두 실제 버튼 클릭 후 클립보드가 HTML 원문과 일치 |
| 발표 중 복사 | 회차별 대표 프롬프트 전체 복사 확인, 3개 |

## 보존과 검증 범위

- DESIGN.md, tokens.css, base.css, shared.js의 SHA-256은 workflow-state.md의 최초 기준과 동일하다.
- data/site.js의 instructor 객체는 Git HEAD와 동일하다.
- git diff --check 통과. 기존 3회 제작 변경은 그대로 보존했다.
- 실제 Gemini에 프롬프트를 보내 생성 결과를 평가하거나 Google 계정에 로그인·배포·저장하는 검증은 수행하지 않았다. 프롬프트의 실행 결과는 수업 전 학교 계정으로 사전 확인해야 한다.
- 로컬 검증 파일과 화면 이미지는 Git에서 제외된 work-temp에 있다. 기존 정리 작업의 자동 승인 거절 이후 재삭제를 시도하지 않았다.
- 커밋·푸시·배포는 수행하지 않았다. 다음 회차 제작 전 사용자 피드백을 받는다.
