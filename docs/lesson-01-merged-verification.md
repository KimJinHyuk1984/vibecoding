# 통합 1회 구현 및 검증 — 내 게임을 우리 반 서비스로

검증일: 2026-10-01

## 반영한 요청

사용자는 시간 제한을 두지 않고 기존 1·2·3회를 하나의 1회에 합치도록 요청했다. 단순히 세 페이지를 이어 붙이지 않고, 학생이 자기 게임을 만들어 꾸미고 기록을 저장한 뒤 친구와 사용하는 하나의 프로젝트로 다시 구성했다.

필수 흐름: 바이브코딩 소개·무한의 계단 체험 → 첫 게임 → 내 제목과 분위기 → 기록장 준비 → AI에게 Code.gs와 게임 HTML 연결 요청 → 실제 점수 저장 → 공유 랭킹 → 보관과 다음 앱 아이디어.

- 시간·분 단위 진도 표시를 제거하고 네 가지 성취 확인 지점을 둔다.
- 기본 프롬프트 6개, 선택 미션 3개, 도움 1개다. 모두 클릭해 전체를 복사할 수 있다.
- 최근 5판 기록, 휴대폰 개선, 20칸 도착은 공유 랭킹 완성 후 선택한다. 도움 프롬프트는 처음 게임부터 저장·랭킹까지 어느 단계에서도 사용할 수 있다.
- Code.gs는 학생이 자기 게임 HTML을 제공한 AI 채팅에서 직접 요청한다. 교사 코드를 받는 단계는 없다. 시트 주소는 SHEET_URL 설정에 전체 주소를 붙인다.
- 초반에는 미리보기나 로컬 HTML, 시트 저장부터는 Apps Script의 배포 주소를 사용한다. 마지막에는 같은 주소에서 친구가 쓸 수 있는지 실제로 확인한다.
- 이전 4~13회 주제는 새 2~11회로 옮겼다. 통합 1회만 공개 상태다. 새 2회 주제는 학교 축제 부스 예약이며 본문을 제작하지 않았다.
- 기존 lesson-02와 lesson-03 경로는 통합 1회 해당 부분으로 이동한다. 향후 새 회차 제작 때 교체할 호환 페이지다.

## 보존과 한계

DESIGN.md, tokens.css, base.css, shared.js의 SHA-256과 instructor 객체는 최초 기준을 유지했다. 공통 파일은 수정하지 않았다. 강의 전용 widgets.js에서는 목록의 고정 안내 문구만 이번 통합에 맞게 수정했다. JavaScript 구문과 git diff --check를 확인했다.

이전 페이지·운영 메모의 통합 전 사본은 Git에서 제외된 work-temp에 보관한다. 이전 검증 보고서는 당시 이력으로 남기고 최신 보고서로 연결했다. 커밋·푸시·외부 배포는 실행하지 않았다.

실제 Gemini에 프롬프트를 보내거나 Google 계정에서 인증·배포·Sheets 저장을 수행하지 않았다. 학생마다 AI 생성 코드가 달라지므로 학교 계정의 접근 가능 여부와 실제 저장·공유를 교사가 사전 확인해야 한다. 위 검증은 강의 페이지와 체험 기능에 대한 것이며 학생별 생성 앱의 작동 보증은 아니다.
