## 반영한 요청

사용자의 “5회로 가자~” 지시에 따라 plan2.md의 다음 프로젝트를 작성했다. 고등학생이 API로 급식·예보를 조회하고 출처가 있는 자료로 답하는 도우미를 만드는 강의다. 기존의 복사형 자연어 프롬프트와 AI가 만든 전체 파일을 옮기는 방식을 유지했다.

- 11개 섹션, 프롬프트 9개(기본 7·조건부 AI 연결 1·도움 1), 위젯 5개(모형 1·체크 3·제작 기록 1).

- 실제 정보 API 연결이 기본 목표이며, 세 질문의 기본 답변은 규칙 기반임을 표시한다. 실제 AI 연결은 승인된 서비스·문서·모델·예산을 확정한 뒤 진행하는 선택 확장이다.

- 키를 발급받지 못한 학생은 급식 연결 대기를 명시하고 날씨부터 실제 연결한다. 미실행을 성공으로 체크하지 않는다.
- 허브 1~5회 ready, 6회 coming. 4회 다음 링크와 정적 안내를 연결했다. 마지막 6회 본문은 작성하지 않았다.

## 확인하지 않은 범위

실제 Google 계정에서 권한 승인·배포하거나 학생별 AI 생성 index.html·Code.gs를 실행하지 않았다. 공개 나이스·Open-Meteo 엔드포인트의 읽기 호출을 시도했으나 이 환경에서는 fetch가 실패해 실제 응답을 확인하지 못했다. 따라서 API 응답, 인증키, 서버 캐시·호출 한도·별도 계정 접근은 운영 메모의 시험표로 수업 전 확인해야 한다.

AI 제공자는 선정하지 않았다. 선택 프롬프트에는 승인된 서비스·공식 문서·모델·한도를 채우도록 하고, 미확정 시 API 형식을 추측하지 않도록 명시했다. 실제 AI POST·응답·비용·중지 기능은 미실행이다. 기존 plan2.md의 조건부 확장 범위다.

수행: 5회 제작 → lesson-05, widgets.js, lecture.css, 메타·연결 링크·README·운영/검증 문서 → 강의 페이지 검사 통과. 다음 6회는 계획된 준비 중 상태다. 검증용 스크립트·프로필·캡처는 Git 제외 work-temp에 남겼다.

이번 5회 작업의 커밋·푸시·외부 배포는 수행하지 않았다. 5회 피드백 이후 다음 회차로 진행한다.
