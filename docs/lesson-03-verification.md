# 3회 구현 및 검증 — 우리 반 게임 랭킹

> 이전 ‘교사 코드 제공’ 흐름의 검증 기록이다. 현재 수업은 학생이 AI에게 두 파일을 요청하는 방식이며, [최신 검증](lesson-03-ai-flow-verification.md)을 기준으로 한다. 아래의 서버 검사 결과는 현재 학생별 AI 생성 코드에 적용되지 않는다.

## 반영 범위

사용자의 “3회 가자” 지시에 따라 3회 자료를 작성했다. 2회 게임을 Apps Script HTML 서비스로 옮기고 Sheets에 저장·조회하는 120분 수업이다. 8개 섹션, 복사 프롬프트 8개, 기본 발표 28개 조각과 보충 3개 조각을 구성했다.

페이지에 표시되는 저장·랭킹 체험은 메모리 안에서만 동작하는 예시임을 명시했다. 실제 연결을 위한 서버와 대체 연결 확인용 HTML은 내려받아 Apps Script에 설치할 수 있다. 두 파일은 이 수업을 위해 작성한 코드이며 학생의 실제 계정에 이미 배포된 앱이 아니다.

## 실행한 검증

Chrome 154.0.8037.59의 분리된 헤드리스 프로필에서 브라우저 검사 **69개**, Node VM의 Google 서비스 대체 구현에서 서버 검사 **28개**를 통과했다.

| 검사 | 결과 |
| --- | --- |
| 강의 구성 | 8개 섹션·8개 프롬프트·4개 위젯 정상 초기화 |
| 복사 | 모든 프롬프트의 클립보드 내용이 원문과 일치, 발표 모드에서도 확인 |
| 저장 체험 | 저장 중 표시, 버튼 중복 클릭 방지, 입력 검사, 원본 행과 랭킹 새로고침 구분 |
| 랭킹 체험 | 별명별 최고 기록, 낮은 점수 유지, 동점 순위, 초기화 정상 |
| 모바일 | 375×812에서 가로 넘침 없음, 버튼 높이 44px 이상 |
| 발표 | 기본 28개·전체 31개 조각 검사. 넘침 없음. 최소 본문 약 27.64px, 코드 약 23.69px |
| 명암 | 밝은·어두운 테마 텍스트 대비 통과. 최소 약 6.23 / 8.11 |
| 보관 | 체크·학습 기록 유지, 저장 차단 시 Docs 보관 안내 |
| 파일 경로 | HTTP·저장소 하위 경로·file:// 정상. 목록 왕복, 2회→3회 연결 정상 |
| 내려받기 | 두 실습 파일 HTTP 읽기 정상, 파일 해시 기록 |
| 대체 안내 | 위젯이 로드되지 않아도 정적 설명 유지 |
| 연결 HTML | Google 환경이 없으면 실제 저장 불가 안내 및 저장 버튼 비활성 |
| 비동기 화면 처리 | 대체 RPC로 저장 중 잠금, 저장 후 응답 유실, 같은 ID 재시도 확인 |
| 조회 오류 | 저장 성공 후 조회 실패가 나도 저장 성공 유지, 조회만 재시도 |
| 서버 초기화 | 정확한 열 제목 작성, 재실행 시 기존 행 유지, 잘못된 표 머리 거절 |
| 서버 입력 검사 | 별명·정수·범위·끝없이 모드·기록ID 형식 검증 |
| 서버 중복 검사 | 동일 ID·동일 내용 재전송은 행 추가 없음, 동일 ID·다른 내용 거절 |
| 서버 랭킹 | 별명별 최고, 1·1·3 동점 순위, 내림차순 상위 10명, 직렬화 가능한 반환 값 |
| 서버 잠금 | 저장 예외 시에도 잠금 해제 호출. 실제 Google 동시성은 아래 미실행 범위 참조 |
| HTML·공통 자산 | 중복 ID 없음, 상대 파일·앵커 유효, 공통 파일 4개 및 instructor 유지 |
| 실행 오류 | JavaScript 예외 없음. 기존 강사 사진 부재 이외 예상하지 못한 HTTP 오류 없음 |

발표의 저장 체험·연결 프롬프트, 모바일 강의 체험·다운로드 예제 화면을 이미지로도 확인했다. 원시 검증은 [브라우저·서버 결과](lesson-03-browser-results.json), [발표 조각 측정](lesson-03-overflow.csv)에 있다.

## 미실행 범위

- 실제 Google 계정 로그인·권한 승인·웹앱 배포·Sheets에 쓰기·읽기·학교 조직 접근은 수행하지 않았다.
- 서버의 Apps Script 서비스는 Node VM 및 브라우저 안의 대체 구현으로 검사했다. 이는 실제 Google 서비스의 동작 검증을 대신하지 않는다.
- 실제 여러 학생 계정의 동시 저장과 Google의 운영 한도는 검사하지 않았다. 수업 전 교사가 제공 예제로 직접 확인하도록 [운영 메모](lesson-03-teaching-notes.md)에 절차를 적었다.
- 학생별 2회 게임 코드는 서로 다르므로 AI로 생성될 게임 이식 결과를 실제 계정에서 실행하지 않았다. 대체 HTML은 연결 확인용 화면이며 완성 게임 전체가 아니다.

## 출처 및 보관

Apps Script의 연결 방식·권한·배포 안내는 운영 메모에 연결한 Google 공식 문서를 확인했다. 수업 페이지의 관련 설명 옆에도 출처를 붙였다. 서버와 HTML은 직접 작성했으며 문서의 예제 코드를 전재하지 않았다.

이번 작업은 3회 자료 작성까지다. 커밋·푸시·사이트 배포·Google 서비스 배포는 실행하지 않았다. 검사 서버는 종료했다. 검사 스크립트·화면 이미지·분리된 브라우저 프로필은 Git에서 제외한 `work-temp/`에 남긴다. 이전의 전체 폴더 삭제 차단 이후 재귀 삭제는 재시도하지 않았다.
