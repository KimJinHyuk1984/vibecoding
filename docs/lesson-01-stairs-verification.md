# 1회 피드백 반영 검증 — 무한의 계단

> 통합 이전 시점의 검증 기록입니다. 현재 페이지 기준은 [통합 1회 검증](lesson-01-merged-verification.md)입니다.

검증일: 2026-09-30. 도입 게임을 무한의 계단 방식으로 바꾸라는 사용자 피드백을 반영했다. 이전 버전의 검증은 `lesson-01-verification.md`에 보존한다.

## 반영 내용

- ←: 제자리에서 바라보는 방향만 전환. →: 바라보는 방향으로 한 칸 올라가기.
- 다음 계단과 다른 방향으로 올라가면 종료. 재시작은 점수·위치·방향을 초기화한다.
- 무한 생성과 화면 이동, 현재 칸 수·방향·최고 기록, 모바일 버튼을 제공한다. 제한 시간은 없다.
- 소개, 첫 제작·수정 프롬프트, 테스트 체크리스트, 오류 예시, 파일 저장명, 운영 메모를 같은 규칙으로 수정했다.
- 구성은 120분·9개 섹션·7개 복사 프롬프트를 유지했다. 다음 회차는 작성하지 않았다.

## 결과

Chrome 154의 분리된 임시 프로필에서 64개 브라우저 검증을 통과했다. 테스트 도구는 Node 내장 기능과 Chrome 디버깅 프로토콜을 사용했고 사이트에 의존성을 추가하지 않았다.

| 검사 | 결과 |
| --- | --- |
| ← 방향 전환 | 위치·점수 유지, 좌우 전환 확인 |
| → 올라가기 | 양쪽 방향의 계단 모두 확인, 실제 방향키로 250칸 연속 통과 |
| 무한 계단 | 화면 가로 경계 준수, 장시간 플레이에도 SVG 노드 수 일정 범위 유지 |
| 잘못된 방향·종료 | 해당 판 종료, 이후 조작으로 점수 증가 없음 |
| 재시작 | 0칸·처음 위치·오른쪽 방향 복원, 여러 번 재시작해도 입력 중복 없음 |
| 입력 분리 | 키 누르고 있기 반복 방지, 게임 밖 입력란의 방향키는 게임에 영향 없음 |
| 모바일 | 375×812, 실제 터치 이벤트로 버튼 확인, 버튼 높이 44px 이상, 가로 넘침 없음 |
| 발표 모드 | 게임 조작 중 슬라이드 유지. 기본 33개·보충 포함 34개 조각 전체 검사 |
| 가독성 | 1920×950에서 넘침 없음. 본문 24px·코드 20px 하한 충족, 두 테마 텍스트 대비 통과 |
| 복사 | 7개 프롬프트의 실제 클립보드 내용이 원문과 일치, 발표 모드에서도 확인 |
| 공통 기능 | 체크·기록 저장, 메뉴·모달·테마, 발표 종료 후 복원 통과 |
| 실행 경로 | HTTP 루트·저장소 하위 경로·file://에서 작동 |
| 실패 시 안내 | 위젯 파일 차단 시 정적 조작 설명, 저장소 차단 시 대체 보관 안내 확인 |
| JavaScript | 예외 없음 |
| 보호 자산 | 공통 파일 4개 해시 및 instructor 블록 유지 |

모바일 게임, 발표 게임, 첫 프롬프트 화면을 이미지로도 확인했다. 수치 결과는 [브라우저 결과](lesson-01-stairs-browser-results.json), [발표 화면 측정](lesson-01-stairs-overflow.csv)에 기록했다.

## 검증 범위와 보관

- 실제 학생 계정으로 Gemini에 프롬프트를 전송해 생성한 결과는 검증하지 않았다. 페이지의 게임은 직접 작성한 체험용 예제다.
- 제공되지 않은 `assets/img/instructor.jpg`의 기존 404는 강사 이름 이니셜로 대체 표시된다. 이외의 예상하지 못한 HTTP 오류는 없었다.
- 테스트용 파일과 브라우저 프로필은 Git에서 제외된 `work-temp/`에 남긴다. 이전 작업의 재귀 삭제 차단 이후 전체 폴더 삭제를 재시도하지 않았다.
- 로컬 테스트 서버는 검사 후 종료했다. 커밋·푸시·배포는 수행하지 않았다.
