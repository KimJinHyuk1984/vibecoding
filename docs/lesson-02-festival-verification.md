# 2회 구현 및 검증 — 우리 학교 축제 운영 서비스

검증일: 2026-10-01

## 반영한 요청

사용자의 “새로운 우리 계획에 따라 다음 작업을 시작하자”에 따라 plan2.md의 다음 프로젝트인 2회를 작성했다. 이전 11개 계획의 예약·대시보드를 하나로 묶었다. 학생은 코드를 읽지 않으며 프롬프트를 클릭해 복사하고 자기 HTML과 AI가 작성한 Code.gs 전체를 사용한다.

- 12개 섹션: 체험 → Forms 설문 → 화면 → 서버 연결 → 첫 저장 → 취소 → 규칙 시험 → 대시보드 → 호출 원리 → 보관 → 선택 → 도움.
- 기본 프롬프트 7개, 선택 검색·정렬 1개, 도움 1개. 긴 요청 2개는 발표에서만 분할하며 복사 원문은 유지한다.
- CRUD, 고유번호, 서버 검증, 동시 요청, 중복 방지, 비동기 호출, 집계·필터·정렬·시각화를 짧은 기술 설명으로 연결했다.
- 관심 표와 예약 수, 취소와 삭제, 서버 호출과 외부 API, 로컬 체험과 실제 앱을 구분했다.
- 부스 3개, 정원 2명, 한 차례 운영으로 정하고 실제 두 기기 시험 시나리오를 제공했다.
- 목록을 6개 프로젝트로 변경하고 1·2회만 공개했다. 1회 하단에서 2회로 연결했다. 3회 본문은 작성하지 않았다.

## 보존과 실습 검증의 한계

변경 파일은 lesson-02/index.html, 강의별 widgets.js·lecture.css, data/site.js, 1회 다음 링크, 허브 정적 대체 문구, README와 작업 문서다. DESIGN.md·tokens.css·base.css·shared.js·강사 정보는 변경하지 않았다.

실제 Google 계정의 Forms 생성·응답·권한 승인·Apps Script 배포와 학생별 AI 생성 코드 실행은 미실행이다. 실제 예약·동시 요청·취소·집계 검증은 운영 메모의 현장 시나리오를 따라 수행해야 한다. 본 검증은 강의 페이지와 로컬 체험에 대한 결과다.

이번 작업은 2회 콘텐츠까지다. 다음은 사용자의 2회 피드백 반영이며, 3회는 별도 진행 지시 후 작성한다. Git 커밋·푸시·외부 배포는 실행하지 않았다. 검증 스크립트와 캡처는 Git 제외 work-temp에 보관했다.
