# 2회 구현 및 검증

> 통합 이전 시점의 검증 기록입니다. 현재 페이지 기준은 [통합 1회 검증](lesson-01-merged-verification.md)입니다.

## 반영 범위

사용자의 “좋아~ 2회로 가자” 지시에 따라 2회 「같은 게임, 완전히 다른 스타일」을 작성했다. 1회의 무한의 계단을 이어서 요구사항·디자인·게임 규칙·테스트·버전 보관을 배우는 구성이다.

- 120분, 휴식 10분 포함. 8개 섹션, 클릭 복사 프롬프트 7개.
- 테마 비교 예제: 기본 / 우주 / 도서관. 플레이 상태를 유지하며 화면 스타일만 바꾼다.
- 도착 예제: 20칸에서 성공하고 입력을 멈춘다. 학생 제작 앱에는 끝없이 / 20칸 도착 두 모드를 요구한다.
- 기존 조작 유지: ←는 제자리 방향 전환, →는 바라보는 방향으로 한 칸 올라가기.
- 1회 하단·시리즈 목록에 2회 링크를 추가했다. 3회 이후는 준비 중이다.

## 검증 결과

분리된 Chrome 154.0.8037.59 헤드리스 프로필에서 브라우저 검사 71개를 통과했다. Node 내장 기능으로 실행했으며 사이트에 npm 의존성이나 외부 자산을 추가하지 않았다.

## 검증 범위와 보관

- 실제 학생 계정으로 AI에 프롬프트를 보내 생성한 결과는 검증하지 않았다. 두 체험 게임은 직접 작성한 로컬 예제다.
- 기존의 강사 사진 파일 부재로 발생하는 `assets/img/instructor.jpg` 404는 이름 이니셜로 대체 표시된다. 이외에 예상하지 못한 HTTP 오류는 없다.
- 검사 과정의 이미지·스크립트·임시 브라우저 프로필은 Git에서 제외된 `work-temp/`에 보관한다. 이전의 전체 폴더 삭제 차단 이후 재귀 삭제를 재시도하지 않았다.
- 로컬 검사 서버는 종료했다. 커밋·푸시·배포는 실행하지 않았다. 2회 사용자 피드백을 받은 뒤 다음 회차를 진행한다.
