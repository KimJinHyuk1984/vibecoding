## 제한과 미실행

- 기존 템플릿은 강사 사진 경로를 지정하지만 실제 파일은 없다. 요청 시 404 후 이니셜로 표시되며 강사 정보는 수정하지 않았다.
- 실제 학생의 Google 계정에 로그인하거나 Gemini에 프롬프트를 전송하지 않았다. 학생 계정의 서비스 접근은 교실에서 확인해야 한다.
- 자동 생성되는 학생 게임 결과는 매번 다를 수 있으므로 모든 생성 결과의 동작을 보장하는 검증은 아니다.
- 원본 PPTX 전수 이미지 OCR, 실제 기기의 터치 입력, 공개 배포는 미실행.
- 네이티브 브라우저 연결이 없어 별도 임시 프로필의 headless Chrome으로 검증했다. 임시 프로필은 사용자의 기존 브라우저 프로필과 분리했다.
