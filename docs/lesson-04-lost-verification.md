# 4회 구현 및 검증 — 우리 학교 분실물 센터

검증일: 2026-10-02

## 구현 범위

사용자의 “좋아! 다음 작업 하자” 지시에 따라 plan2.md의 4회를 제작했다. 사진을 포함한 분실물 등록·검색·반환을 하나의 서비스로 연결하는 강의다. 코드를 읽지 않는 학생을 위해 복사형 자연어 요청과 AI가 만든 두 파일 전체를 붙이는 흐름을 유지했다.

- 12개 섹션, 프롬프트 9개(기본 7·선택 1·도움 1), 위젯 6개(체험 1·체크 4·제작 기록 1).
- 기본 발표 34개, 보충 포함 38개. 프롬프트 02·03·04·06을 발표에서 나누되 복사는 전문.
- 글자 저장 v1 → 사진·검색 v2 → 반환·접근 범위 v3 순서. 실제 저장 전에 미리보기를 구분한다.
- 사진은 Drive, 연결 번호·물건 정보는 Sheets. 제한된 원본을 실행 계정이 읽어 전달하는 구조와 웹 앱 접근 범위를 설명한다.
- 실제 앱의 반환 기능은 운영자의 시트 메뉴로 제한한다. 로컬 체험의 반환 버튼은 역할을 경험하는 모형임을 명시했다.
- 허브 1~4회 ready, 5·6회 coming. 3회 다음 링크를 4회로 연결했다. 5회 본문은 만들지 않았다.

## 실행 결과

## 미실행과 다음 조건

실제 Google 계정의 배포·Drive 업로드·사진 읽기·서버 권한·운영자 반환 메뉴와 학생별 AI 생성 코드는 실행하지 않았다. 실제 파일 형식·크기 경계, 동시 업로드·부분 실패 복구, 교차 계정 접근은 운영 메모의 사전 시험표로 확인해야 한다.

수행: 4회 제작 → lesson-04, widgets.js, lecture.css, 메타·연결 링크·README·문서 변경 → 위 검사 통과. 공통 보호 파일과 이전 본문은 유지했다. 미해결 교육적 선택지는 없으며 5·6회는 계획된 준비 중 상태다. 검증 스크립트·프로필·캡처는 Git 제외 work-temp에 남겼다.

이번 4회 변경의 커밋·푸시·외부 배포는 수행하지 않았다. 4회 피드백 이후 다음 회차로 진행한다.
