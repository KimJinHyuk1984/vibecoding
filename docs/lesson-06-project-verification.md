# 6회 구현 및 검증 — 내 아이디어를 실제 서비스로

검증일: 2026-10-05

## 반영한 요청

사용자가 5회 작업 이후 “다음으로 진행하자”라고 지시해 `plan2.md`의 마지막 프로젝트를 작성했다. 코드를 읽지 못하는 학생이 문제와 세 기능을 정하고, 전체 파일을 AI에게 직접 요청해 제작·오류 해결·친구 테스트·개선·공유를 경험한다.

- 12개 섹션, 복사 프롬프트 9개(기본 8·다음 아이디어 선택 1), 위젯 5개(조합 보드·확인표 2·성찰 2).
- 기본 발표 34개, 보충 포함 35개. Code.gs 요청은 두 조각으로 발표하되 복사는 전체 원문이다.
- 학생이 원하는 동작과 실제 관찰을 설명한다. 코드 일부를 찾아 고치는 지시나 교사 완성 코드 다운로드는 없다.
- 첫 기능을 완성하고 실제 Google 결과를 확인한 뒤 다음 기능을 연결한다. 오류 재현과 재시험, 중복·실패·접근 범위 시험, 개선 전후 비교를 포함한다.
- 현재 파일 저장과 배포 버전의 차이, 코드 복귀와 데이터 복원의 차이, 운영 종료 시 정리할 대상을 설명한다.
- 허브의 6개 프로젝트를 모두 연결하고 5회 하단·정적 목록·README를 갱신했다. 계획과 앞선 학습 본문은 유지했다.

## 실행한 검사

Chrome 154.0.8037.95의 격리 headless 프로필, Node 정적 서버와 CDP를 사용했다. **브라우저 검사 92개 통과**, 런타임 예외 0개다. 마우스·키보드 입력과 실제 브라우저 클립보드를 사용했다. 프리셋 데이터 비교 일부는 DOM change를 사용하고 네이티브 select의 키보드 조작은 별도 확인했다.

## 변경 경계와 미실행 범위

보호 파일 `DESIGN.md`, `tokens.css`, `base.css`, `shared.js`의 SHA-256과 `instructor`는 동일하다. `plan.md`·`plan2.md`와 기존 1~4회 HTML은 HEAD와 대조했고, 5회는 하단 6회 이동 링크만 바꿨다. 새 JS 구문, 로컬 파일 링크, `git diff --check`를 확인했다. 실제 학생 자료·키·계정·원본 PPTX는 추가하지 않았다. 검증용 스크립트·프로필·캡처는 Git 제외 `work-temp`에 보관한다.

실제 Google 로그인·권한 승인·Apps Script 배포와 학생별 AI 생성 `index.html`·`Code.gs`는 실행하지 않았다. 생성된 학생 앱의 권한·자료 보존·API·트리거 동작은 이 강의 페이지 검사로 보증하지 않는다. 실제 친구의 관찰과 개선 성과도 수업에서 직접 기록해야 한다.

이 작업은 6회 본문 작성과 로컬 검증까지다. 커밋·푸시·외부 배포는 수행하지 않았다. 1~6회 본문을 작성했으며 6회 사용자 피드백을 기다린다.
